# Shift Diary PWA

## Install
1. Upload the contents of this folder to a static web host that supports HTTPS.
2. Open the hosted `index.html` in Safari or Chrome.
3. On iPhone/iPad in Safari, tap **Share → Add to Home Screen**.
4. On desktop Chrome/Edge, use the install icon or browser menu.

The app shell is cached for offline launch after the first successful visit. Incident data is stored locally in the browser on this device; it is not automatically synced between devices.

PDF preview/print uses the browser's print dialog. If the dialog is open, cancel/close it first, then use the preview's **Close preview** button.
